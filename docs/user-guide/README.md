# User guide

`RoadWatch-User-Guide.pptx`: the PowerPoint user guide for v1.2.0 (39 slides, 16:9), one section per role:
Introduction (what the guide covers, the three roles, what is new in 1.2.0, getting started), 01 Reporter (Android
app), 02 Traffic Officer (app and website, including On duty, nearby alerts and confirm or reject on scene),
03 Administrator (website, including report priority, the Users toolbar and the alert range), 04 Good to know (the
website Guide, your account, troubleshooting, privacy and accessibility) and Closing. Slides about new features carry
an amber "NEW IN 1.2" tag. Speaker notes are on the title, section and some content slides.

The screenshots come from the Figma exports in `docs/ui-design/screens/`. When a screen changes, export it again
there and replace the picture in the deck (right-click the picture, Change Picture). Text is in Arial so it looks the
same on every computer; the colors are the RoadWatch theme (Design, Variants, Colors). Addresses: website
`www.roadwatch-ph.me`, Android app `www.roadwatch-ph.me/app`.

Owner: Princess Lorellyn Isip (Documentation Lead). First draft Oct 27; v1.2.0 edition Oct 30.
