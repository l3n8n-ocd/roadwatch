# User guide

`RoadWatch-User-Guide.pptx`: the PowerPoint user guide for v1.1.0 (31 slides, 16:9), one section per role:
Introduction, Reporter (Android app), Traffic Officer (app and website), Administrator (website), For everyone
(account, troubleshooting, privacy and accessibility) and Closing. Speaker notes are on the title and section slides.

The screenshots come from the Figma exports in `docs/ui-design/screens/`. When a screen changes, export it again
there and replace the picture in the deck (right-click the picture, Change Picture). Text is in Arial so it looks the
same on every computer; the colors are the RoadWatch theme (Design, Variants, Colors).

Owner: Princess (Documentation Lead). First draft generated Oct 27 from the Figma screens, for her to edit.
